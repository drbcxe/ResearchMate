**一、七天“开发完成”的具体含义**

七天目标为本地可部署的 v0.1，以下功能全部接通前后端，并有正常和失败场景验收：

| 功能 | 第七天必须看到的结果 |
|---|---|
| 登录与配置状态 | 单用户登录、退出；查看模型是否配置与连通，真实 Key 仅在后端 |
| 项目与文件 | 新建/切换项目、导入规范化 CSV、查看版本与实验列表 |
| 实验比较 | 页面选择或对话触发比较，展示数值、口径、来源行；错误明确 |
| 真实 Agent | 调用支持工具的真实模型，多轮交流、工具选择、有界执行 |
| 会话恢复 | 刷新与服务重启后能继续；需要补充信息的流程能恢复 |
| 项目记忆 | 跨会话读取偏好，查看、修改、停用；保留修订来源 |
| 待办与提醒 | 创建/完成待办，创建/改期/取消提醒，到期站内可查询且不重复 |
| 执行与事件 | 后台执行、任务状态、SSE 业务事件、失败原因与结果关联 |
| 交付 | Docker Compose 可复现，源码/锁文件/迁移/说明在 GitHub，CI 通过 |

“站内已送达”指通知记录已落库并能被页面查询；“用户已读”是另一个字段。单用户本地运行是本版部署范围。

完整路线中的向量检索、MCP、研究模型服务、团队权限、外部聊天通知保留第二阶段。它们不在 v0.1 放占位按钮，也不作为七天验收已完成项。你已有模型以后接入相同工具/任务边界，不改变主干。

第一次开发，56 小时是紧凑预算，不能保证任意依赖、API 和网络故障都在预算内解决。每天预留联调；某项验收未通过就记录并修复，不能以“到了第七天”代替可用性。

**三、固定架构，减少临时换技术**

采用 LovAgent 的职责分层：React/TS/Vite 前端 → FastAPI 路由 → LangGraph 主图/子图 → 业务服务与工具 → 数据与交付。保持你的新项目独立代码与历史。

本版使用 Python 3.12、uv、React/TS/Vite、pnpm、FastAPI、Pydantic、LangGraph、SQLAlchemy/Alembic、PostgreSQL、Celery/Redis。Python 使用 uv 安装该小版本当前可用补丁；Node 以满足 Vite 与 pnpm engines 的受维护版本为准。实施当天安装稳定依赖，提交锁文件，七天中不随意整体升级。

LovAgent 的图和服务结构用于学习；它旧的依赖范围、SQLite 配置与进程内调度不直接作为新项目配置。按 [架构与接口约定](./架构与接口约定.md) 实现。
